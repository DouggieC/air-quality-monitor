Predictions still failing with `ValueError: Input data must be 2 dimensional and non empty`

Debug output shows:

- But "Unique city/horizon combos: 66" (should be 88)
- Medium range batch is empty: `model_input shape: (0, 52)`

Root cause: Horizon calculation in `_create_temporal_features` (line 194):
```python
df["horizon"] = (df["forecast_for"] - df["collected_at_we"]) / pd.Timedelta(hours=1)
```
Uses `collected_at_we` (when forecast was fetched) instead of `as_of`. This produces wrong horizon values.

Added debug print at line 195:
